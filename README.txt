QuickShare Ultra Premium
========================

1. Extract this ZIP.
2. Make sure Node.js is installed.
3. Open Command Prompt in this folder.
4. Run: npm start
5. Open http://localhost:8787
6. For another device on the same Wi-Fi, open the LAN address printed in the terminal.

Keep the server window open while sharing. Both devices must connect to the host laptop.
Files are stored in ./shared-files. On hosted platforms such as Render, uploaded files may be temporary unless persistent storage is configured.
